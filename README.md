# Comparative Life Cycle Assessment and Carbon Reduction Strategies for a Copenhagen Metro Station

## Project Overview

This project develops a comparative cradle-to-construction Life Cycle Assessment (LCA) framework for a hypothetical underground metro station in Copenhagen.

The objective is to quantify construction-related greenhouse gas emissions and evaluate potential reductions through low-carbon construction materials, circular economy strategies, and scenario analysis.

## Research Objectives

- Estimate baseline construction emissions across life-cycle modules A1–A5.
- Assess the contribution of concrete and steel to total embodied carbon.
- Compare conventional and low-carbon construction material alternatives.
- Evaluate carbon reduction potential and cost trade-offs.
- Develop a reproducible carbon accounting model using Excel and Python.

## Methodology

The project follows LCA principles based on ISO 14040, ISO 14044, and the construction-product framework EN 15804+A2.

**System Boundary:** A1–A5 (cradle-to-construction).

**Case Study:** Hypothetical underground metro station in Copenhagen.

## Tools
